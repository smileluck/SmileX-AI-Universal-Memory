# 优化 3+4：Cross-Encoder Rerank + 写入时事实抽取

## 优化 3：Cross-Encoder Rerank（检索侧，先做，独立低风险）

### 新增 `src/smilex/memory/lifecycle/reranker.py`（照抄 Embedder 模式）
- `Reranker` Protocol：`async rerank(query: str, documents: list[str]) -> list[float]`
- `NoopReranker`：默认实现，不干预排序
- `CrossEncoderReranker`：懒加载 `sentence_transformers.CrossEncoder`，`asyncio.to_thread` 包住 `predict`（对齐 promotion.py:210 模式）；参数 `model_name` 默认 `BAAI/bge-reranker-v2-m3`（可配置）、`max_candidates=50`、`batch_size=16`（防 MPS 大批次卡死）
- `RerankerConfig` frozen dataclass（`backend: "noop"|"cross-encoder"`、`model_name`）+ `get_reranker()` 工厂
- ImportError 提示装 `smilex-ai-memory[rerank]`；pyproject 新增 `rerank = ["sentence-transformers>=3.0"]` extra

### 接线 `context_builder.py`
- `ContextBuilder.__init__` 加 `reranker: Reranker | None = None`
- `build_context`：`_collect` 之后、`_greedy_fill` 之前，对 L1/L2 候选按层分组 rerank（不动 L0）：每层取前 `max_candidates` 条，rerank 分数 min-max 归一化到 [0,1] 替换原 RRF 分数，层优先级排序逻辑不变，更新 L1 score contract 注释
- `MemoryMiddleware.__init__` 透传 `reranker`；`server/config.py` 加 `reranker: str = "noop"`

### 测试与验证
- `tests/unit/test_reranker.py`：Noop 直通、懒加载不 import、max_candidates 截断、归一化；fake reranker 注入验证排序翻转
- `benchmarks/retrieval_baseline/run_baseline.py` 加 `--rerank` 开关，conv-26 R@10 对比（96.7% 基线，目标 single_hop 提升）

## 优化 4：写入时事实抽取（core 注入式，默认 no-op 保持零 LLM）

### 前置修复：promotion 尊重 WriteRequest.time_range
- 根因：`promotion.py:157` INSERT 用 created_at 墙钟忽略 time_range → benchmark 被迫用 anchor_times 文本匹配回填；事实抽取改变文本后该 hack 必坏
- 修法：promotion 路径携带 `time_start`（来自 WriteRequest.time_range.start），INSERT 优先用它、缺省回退 created_at；补单测

### 新增 `src/smilex/memory/lifecycle/extractor.py`
- `FactExtractor` Protocol：`async extract(content: str) -> list[str]`
- `PassThroughExtractor`：默认，返回 `[content]`（现状行为）
- `LLMFactExtractor`：OpenAI 兼容 API（env `SMILEX_EXTRACT_API_KEY/BASE_URL/MODEL`），mem0 风格原子事实抽取 prompt（一句一事、保留日期/实体/待办/拥有物/偏好），temperature 0、失败降级返回原文整块
- `MemoryMiddleware.__init__` 加 `fact_extractor` 参数，默认 PassThrough

### 接线 `MemoryMiddleware.write()`
- `put()` 前：`facts = await self._extractor.extract(request.content)`，每条 fact 独立 FuzzyMemory（同 scope/importance/time_range），逐条 `promotion.put`
- `facts_bypass_l0=True` 行为开关（仅非 PassThrough 时生效）：短事实跳过 L0 直送 promotion，保证可检索；benchmark 侧 promotion_threshold=0 不受影响

### Benchmark 接入与验证
- locomo.py / longmemeval.py 加 `--fact-extraction` 开关，构造 LLMFactExtractor 注入；checkpoint 文件名加 `_fx` 后缀
- 冒烟：LME 6 题（multi-session 计数题最受益）→ 30 题对比 93.3% 基线（需 GLM key 的部分给命令用户跑）
- `tests/unit/test_extractor.py`：PassThrough、LLM 失败降级、多事实入 L1 + FTS 可检索
