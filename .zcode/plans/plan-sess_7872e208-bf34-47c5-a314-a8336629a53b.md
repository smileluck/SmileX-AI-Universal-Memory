为 SmileX-AI-Universal-Memory 新增 LongMemEval 记忆质量 benchmark（对标 mem0 的评测），使用 BGE-M3 embedder + OpenAI 兼容 API 做 QA 生成与 LLM-as-judge。

新增 benchmarks/longmemeval/ 目录（不改 src/smilex 核心代码）：
1. download_dataset.py — 从 HF 下载 longmemeval_s，缓存到 data/（gitignore）
2. llm_client.py — OpenAI 兼容客户端，环境变量 OPENAI_API_KEY / OPENAI_BASE_URL / SMILEX_BENCH_ANSWER_MODEL / SMILEX_BENCH_JUDGE_MODEL（默认 gpt-4o-mini）
3. ingest.py — 每样本独立临时 db，session 文本经 MemoryMiddleware.write() 灌入（BGE-M3，走 L0→L1 promotion）
4. answer.py — recall()（token_budget=4000）构建上下文 → LLM 生成答案，abstention 题允许拒答
5. judge.py — LLM-as-judge 对比 gold answer
6. run_benchmark.py — 主入口，输出总分 + 各题型准确率 + 平均注入 tokens + recall 延迟 p50（控制台 + results/ 下 JSON/MD）

pyproject.toml 加 [benchmark] extras（datasets、openai）；README 加 Benchmark 章节；.gitignore 加 data/ 与 results/。

验证：uv sync --extra embedding --extra benchmark → download → run_benchmark.py --limit 小规模试跑确认链路通畅。
